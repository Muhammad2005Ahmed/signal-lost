# Projects

## Karachi Digital Twin (Final Year Design Project, CT-499)

The full title is "Karachi Digital Twin: Synchronizing PostGIS Microservices with 3D Engine Rendering for Flood Topologies".

The project simulates flood topologies for Karachi.

The team has 4 members.

The supervisor is Dr. Usman Amjad, Associate Professor in the CSIT Department.

The data sources are NASA SRTM DEM elevation data and Karachi monsoon rainfall data.

The database is PostgreSQL with PostGIS, running in Docker on Ubuntu.

The back end is a C# ASP.NET Core Minimal API that uses the D8 flow algorithm.

The 3D front end is built in Unity 3D with HLSL shaders using the Universal Render Pipeline (URP).

The project timeline runs from August 2026 to May 2027.

## Two Lights One Escape

Two Lights One Escape is a split-screen co-operative game built in Unity. It won GameCon, a departmental competition.

Both players are in the same room but cannot see each other. They find hints in the room and open the gate for the other player.

There are 3 levels, and each is solved through cooperation.

In the final level the split screen ends, both players come together and fight the final monster, then escape back out through the mirror. The game began because they had gone into the mirror.

## Sound Mask

Sound Mask is a stealth game built in Unity. It placed 3rd at Global Game Jam.

The player is a thief who steals different items in a house.

An item can only be taken while loud background noise plays, such as a train, birds or the owner's snoring, so the sound of stealing is covered.

If the owner wakes up, the game is over.
